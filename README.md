# Высококонверсионный лендинг «АТС Малиновка»

Одностраничный сайт девелопера загородной недвижимости в Ленинградской области (посёлки Honkaniemi, Sawoda, HYTTE, Юрки, проекты Scandi Barn).

## Стек и архитектура
- **Методология:** 8-блочная конверсионная архитектура (surgay-marketing).
- **Дизайн-система:** «Малиновка Nordic Light» (теплый фон `#FAF7F2`, хвойный `#2D5F3F`, терракота `#C07A56`).
- **Стек:** Семантический HTML5 + Tailwind CSS (CDN) + Vanilla JS (интерактивный ипотечный калькулятор с комбо-ипотекой 2026 года и FAQ-аккордеон).
- **Медиа-ассеты:** локальные оптимизированные изображения фасадов, интерьеров и поселков в папке `assets/`.

## Публикация на GitHub Pages
1. Перейдите в **Settings** репозитория -> **Pages**.
2. В секции **Build and deployment** выберите Source: **Deploy from a branch**.
3. Branch: `main` / folder: `/ (root)`.
4. Нажмите **Save**.
